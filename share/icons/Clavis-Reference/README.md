# Clavis Reference icons

This is a local color variant of [Papirus](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme),
based on package version 20260801. It approximates a supplied desktop screenshot;
it is not the original author's published theme.

Papirus Development Team and contributors own the original SVG artwork. The
original GPLv3 license is included as `LICENSE`. These SVGs retain the original
shapes, with dark gray folder bodies, lavender tabs and brighter emblems. The
theme inherits unmodified icons from the separately installed `papirus-icon-theme`
package. Generated icon caches are intentionally omitted.
